# MAUP 固定尺度最热窗口实验

4 km × 4 km 地图、1 km² 窗口；单热点与双热点各200张，比较四种搜索方法。代码原样摘自原完整包，未修改。

## 运行

推荐 Python 3.12（代码要求3.10及以上）。终端进入本目录，运行：

```bash
python maup_experiment.py --blocks 16 --runs 200 --seed 20261118 --verify --output 复现实验结果
```

数值实验仅用 Python 标准库，无需安装依赖。数据按固定种子自动生成，不读取随附CSV；`--verify`额外核验每类前3张地图。

如需图像，再运行：

```bash
python -m pip install -r requirements.txt
python plot_results.py 复现实验结果
```

中文绘图建议使用装有微软雅黑或黑体的系统。

## 查看结果

`实验结果/`是报告原始结果；`复现实验结果/`是本次重跑结果，不覆盖原结果。

| 方法 | 单热点平均缺口 / 命中率 | 双热点平均缺口 / 命中率 |
| --- | --- | --- |
| 固定网格 | 6.160 / 2.5% | 5.515 / 1.5% |
| 四起点叠加 | 2.510 / 10.5% | 2.190 / 14.0% |
| 100米步长滑窗 | 0.450 / 61.0% | 0.360 / 69.5% |
| 精确滑窗 | 0.000 / 100% | 0.000 / 100% |

打开`方法汇总.csv`看总体结论，`逐地图方法结果.csv`看每张地图的计数、位置、缺口和耗时，`仿真点数据.csv`看原始观测。`生成参数.json`记录各地图参数，另外两个JSON供原绘图程序使用。随附图00、04、05展示窗口与汇总对比。

命中表示达到当前样本的最高计数；精确方法是参照。耗时由本机重新测量，不要求与报告毫秒值完全相同。搜索时间不包括生成数据、建共享索引及绘图。

原程序还会生成竞争诊断文件和扩展图，图中紫色虚线属于附加诊断；这些不参与本报告四方法结论，无需解读。
